- [ ] Integrate an LLM API (OpenAI, Anthropic, or local)
- [ ] Build a CLI or web interface for the AI tool
- [ ] Implement prompt engineering basics
- [ ] Add conversation history / context management
- [ ] Handle API errors and rate limits gracefully
- [ ] Write project README with usage examples

**Description:** Create a tool that uses an LLM to perform a specific task (summarization, code generation, data extraction, etc.). Learn API integration, async requests, and prompt design.

## Stage 03: Automation Tool

- [ ] Identify a repetitive workflow to automate
- [ ] Connect 2+ external services (APIs, webhooks, file systems)
- [ ] Implement scheduling or event-driven triggers
- [ ] Add logging and error notifications
- [ ] Make it configurable without code changes
- [ ] Write project README with architecture diagram

**Description:** Build a tool that chains multiple services together (e.g., fetch data → process with AI → post to Slack → save to Notion). Learn orchestration, reliability, and configuration patterns.

## Stage 04: My Product

- [ ] Define a real problem worth solving
- [ ] Design the product architecture
- [ ] Implement core features incrementally
- [ ] Add authentication and user management
- [ ] Set up CI/CD for automated deployment
- [ ] Write comprehensive documentation
- [ ] Deploy to production
- [ ] Create a launch checklist

**Description:** Synthesize everything learned into a complete, deployable product. This is the capstone — a real thing real people could use. Focus on polish, reliability, and maintainability.
