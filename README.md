# AI-Product-Lab

A learning-by-building workspace for AI-assisted product development.

## Purpose

This repository documents my journey from learning AI-assisted coding to shipping real products. Each project builds on the previous one, introducing new concepts, tools, and patterns incrementally.

## Learning Approach

- **Build real things** — Every project is a working application, not a toy exercise
- **Learn by doing** — Concepts are introduced when needed, not in abstract
- **Document everything** — Learning notes capture decisions, errors, and fixes for future reference
- **Iterate in public** — Commits show the real development process, including mistakes

## Project Stages

| Stage | Folder | Description |
|-------|--------|-------------|
| 00 | `00-Learning-Notes/` | Centralized notes, learning log, and project tracker |
| 01 | `01-First-Web-App/` | A simple web application to learn frontend/backend basics |
| 02 | `02-AI-Tool/` | An AI-powered tool integrating LLMs via API |
| 03 | `03-Automation-Tool/` | A workflow automation tool connecting multiple services |
| 04 | `04-My-Product/` | A complete, deployable product synthesizing all prior learning |

## Navigation

- **Start here:** Read `00-Learning-Notes/PROJECT_TRACKER.md` for the roadmap
- **Track progress:** Update `00-Learning-Notes/LEARNING_LOG.md` after each session
- **Explore projects:** Each numbered folder contains a self-contained project with its own README
- **Reference concepts:** Learning notes link to specific commits where patterns were introduced

4. Log your work in `00-Learning-Notes/LEARNING_LOG.md`
